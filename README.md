# Password Strength Checker

A password validation tool built with **HTML, CSS, and JavaScript**. This project helps users create more secure passwords by checking against common security requirements.

## Features
* **Real-time Validation:** Checks password strength as you type.
* **Security Criteria:** Monitors for length, uppercase, lowercase, numbers, and special characters.
* **Visual Feedback:** Checklist items turn green as requirements are met.
* **Toggle Visibility:** Built-in eye icon to show/hide the password.
* **Responsive Design:** Works on desktops, tablets, and mobile phones.

## Technologies Used
* **HTML5** - Structure
* **CSS3** - Styling and Animations
* **JavaScript** - Validation Logic

* **FontAwesome** - Icons
